OnePresence

What is OnePresence?

OnePresence is a OneShot mod. Instead of a boring ol' Discord Rich Presence status that just says OneShot, this mod expands it by a few!

For maps, it says that you are either exploring the barrens, glen, or refuge (surface & ground)!

Dialogues also work! They're a bit finicky due to Discord rate limiting, but it works (mostly)

This mod REQUIRES a external app inorder to use. That app is also open-source, don't worry.

OneShot installation

  • Make sure to backup your original xScripts.rxdata file and the save.dat file wherever OneShot stores your save files!
  • Download the xScripts.rxdata file from the Codeberg repository.
  • Navigate to your OneShot game directory. Paths are listed below this installation guide.
  • Move your unmodified xScripts.rxdata file out the Data folder.
  • Drop the OnePresence version of the xScripts.rxdata file into the Data folder.

    • OnePresence RPC Handler installation

  • Download the OnePresence_RPC_Handler.exe file from the Codeberg repository.
  • Once downloaded, run it!
  • Make sure OneShot is already running, if not, run it.
  • If OneShot is running, click Enable RPCand enjoy!
  • Adjust the path to the .txt file for OnePresence if necessary.
  • You can manually edit the details & state if necessary.

    • Paths to OneShot

    Windows: C:\Program Files (x86)\Steam\steamapps\common\OneShot\Data
 Linux:   ~/.steam/steam/steamapps/common/OneShot/Data
 macOS:   ~/Library/Application Support/Steam/steamapps/common/OneShot/Data

    Troubleshooting

    Q: My game crashes immediately upon launch.
    A: Make sure you have replaced your unmodified xScripts.rxdata with the OnePresence xScripts.rxdata version, Or, if in some cases, OneShot pushed an update that broke the mod. And, to end your game if the game crashed, you will have to open Task Manager, and end the process there.

    Q: How do I revert back to the original vanilla game?
    A: Restore your backed-up xScripts.rxdata file, or verify game file integrity via Steam properties.

    Q: Windows Defender/my antivirus flags the file (.rxdata) as a virus
    A: This shouldn't happen, since it's not happening for me on Windows Defender, (W11 LTSC), Add the .rxdata as a exclusion to the antivirus. I assure you it's safe, literally open source. If you don't trust me, you can extract the .rxdata and find out, or look at the .rb file i uploaded.

    If a problem you are having is not listed here, please contact me, or try to fix it yourself.
